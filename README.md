# ROM Log

A personal log of the Pokémon ROM hacks and fan games I've played: what I thought of them, the teams I used, and how far I got. Live site: https://veturian.github.io/romlog/

## What's on the site

- **Now** – what I'm playing at the moment with progress and where I left off, what's up next, recently finished games, and a running session log of recent play.
- **Library** – every game I've tracked, searchable and filterable by status, type, base game and rating. Open a game to see its team, rating, notes and session history. Games I've played more than once keep each playthrough, with its own team and version.
- **Stats** – a look across the whole collection: how many games I've finished versus dropped, ratings given, completions over time, the base games hacks are built on, and which Pokémon I've used most.

Each game is marked **Playing**, **Completed**, **Abandoned**, **Not Started** or **Not Interested**, and is labelled as a ROM hack or a fan game. Fan games are standalone projects with no base ROM. The site has light and dark modes.

## About

This is a personal project, shared for anyone curious about the games or looking for ideas on what to play. Ratings and notes are my own opinions.

It's a static site on GitHub Pages. Sprites come from the [PokeAPI sprites](https://github.com/PokeAPI/sprites) project, and visits are counted anonymously with [GoatCounter](https://www.goatcounter.com/).
